# Off-Season Tracker

Johann's off-season tracker, 30 Sep 2026 to league on 1 Mar 2027: daily habits in time order, a season grid, a system map for work, and a Sunday review.

## Hosting
Served with GitHub Pages from the `main` branch root. Open the Pages URL in Safari on iPhone, then Share → Add to Home Screen.

## Data
Everything is saved on the device (localStorage). Use **Plan → Backup → Export backup** after each Sunday review and keep the file in iCloud Drive. **Restore from file** loads it back.

## Updating
After changing any file, bump `VERSION` in `sw.js` so phones pick up the new version.
